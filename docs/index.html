SG Transit Planner

An open-source tool that uses public data to find where Singaporeans live more than a 10-minute walk from any MRT station, today and after every line LTA has announced, and suggests where new stations and lines could go. It gives more weight to homes whose nearest station is already packed at rush hour.

Gap map →Underserved homes, new BTO and land-sale sites, LTA's planned network by year, and proposed lines with the reasons for each. Pixel MRT sim →Watch rush hour build up train by train. Tap a train to look inside, and ride Jurong East → Raffles Place.

Data: LTA DataMall (passenger volume, platform crowd), URA Master Plan 2019 rail layer, HDB Property Information via data.gov.sg, HDB building footprints, LTA/URA/HDB announcements (sources are listed in the data files). Built to support planners, not to replace them. Proposals are screening-level, not engineering alignments. Source code (MIT)
