Station figures are LTA DataMall monthly tap-in/tap-out totals. Interchanges report one combined figure, which is counted in every line it serves. "Per day" divides by the number of weekdays or weekend days in the month; public holidays are not taken out. LTA only keeps the last 3 months, so the data bot archives each month as it appears and the history grows from Aug 2026.
